# 小程序模块说明

> 适用范围：`github.com/jcbowen/wego/miniprogram`，微信小程序服务端 API。

## 一、初始化

```go
import (
    "github.com/jcbowen/wego"
)

mpCfg := &wego.MiniProgramConfig{
    AppID:     "wx1234567890",
    AppSecret: "your_app_secret",
}

// 方式一：通过 WeGo 入口（推荐，E 版构造返回 error 而非 panic）
w, err := wego.NewE(mpCfg)
if err != nil {
    panic(err)
}
client, err := w.MiniProgramE()
if err != nil {
    panic(err)
}

// 方式二：模块级构造
// client, err := miniprogram.NewClientE(mpCfg)                    // 默认文件存储
// client, err := miniprogram.NewClientWithStorageE(mpCfg, store)  // 自定义存储
```

> ⚠️ `miniprogram.NewClient` / `NewClientWithStorage` 在配置或存储非法时会 `log.Panic` 终止进程。
> 依赖库不应越权决定宿主进程生死，请统一改用 `NewClientE` / `NewClientWithStorageE`；
> 旧构造已标注 `Deprecated`，仅为兼容保留。
>
> 默认存储目录为 `./runtime/wego_storage`，需确保进程对该目录有读写权限。

**access_token 管理**：`GetAccessToken` 自动完成获取、缓存与刷新——

- 令牌缓存于 `TokenStorage`，带 5 分钟过期安全余量（避免网络延迟导致临界过期）
- 读锁查缓存 + 写锁双重检查，并发调用不会重复刷新
- 可通过构造 opts 注入自定义 `debugger.LoggerInterface` 与 `core.HTTPClient`（或运行期 `SetLogger` / `SetHTTPClient`）

## 二、接口一览

| 方法 | 说明 | 官方接口 |
|---|---|---|
| `Code2Session` | 登录凭证校验，换取 openid / session_key | /sns/jscode2session |
| `GetPhoneNumber` | code 换取用户手机号（可选传 openid 校验绑定关系） | /wxa/business/getuserphonenumber |
| `SendSubscribeMessage` | 发送订阅消息 | /cgi-bin/message/subscribe/send |
| `MsgSecCheck` | 文本内容安全检测（v2 同步，便捷方法） | /wxa/msg_sec_check |
| `MsgSecCheckFull` | 文本内容安全检测（v2 同步，完整参数，支持 title/nickname/signature/head_avatar） | /wxa/msg_sec_check |
| `MediaCheckAsync` | 音视频内容安全检测（v2 异步，结果走消息推送） | /wxa/media_check_async |
| `GetWxaCode` | 获取小程序码（带 path，总数上限 10 万） | /wxa/getwxacode |
| `GetWxaCodeUnlimit` | 获取不限量小程序码（带 scene） | /wxa/getwxacodeunlimit |
| `CreateWxaQrcode` | 获取小程序二维码（旧接口，总数上限 10 万） | /cgi-bin/wxaapp/createwxaqrcode |
| `GetStableAccessToken` | 稳定版 access_token（不写入缓存，不改默认取 token 路径） | /cgi-bin/stable_token |
| `DecryptUserInfo` | 解密用户数据（encryptedData），含水印 appid 校验 | 客户端数据解密 |

## 三、完整调用示例

### 登录与手机号

```go
ctx := context.Background()

// 前端 wx.login 取得的 code
session, err := client.Code2Session(ctx, "js_code_from_wx_login")
if err != nil {
    return err
}
// session.OpenID / session.SessionKey / session.UnionID

// 前端 button open-type="getPhoneNumber" 取得的 code（一次性，用后即失效）
phone, err := client.GetPhoneNumber(ctx, "phone_code")
if err != nil {
    return err
}
// phone.PhoneInfo.PurePhoneNumber / phone.PhoneInfo.CountryCode
```

### 订阅消息

```go
_, err = client.SendSubscribeMessage(ctx, &miniprogram.SendSubscribeMessageRequest{
    ToUser:     session.OpenID,
    TemplateID: "template_id",
    Page:       "pages/index/index",
    // MiniprogramState: miniprogram.SubscribeMsgStateTrial, // formal/trial/developer，不传由微信按默认处理
    Data: miniprogram.SubscribeMessageData{
        "thing1": {Value: "审核通过"},
        "time2":  {Value: "2026-10-23 10:00"},
    },
})
```

### 内容安全检测（v2）

> v2 接口 `openid` 与 `scene` 为必填，缺失时微信直接报错；本库已提前本地校验。
> openid 对应的用户需在**近两小时内访问过小程序**。

```go
// 便捷方法：文本同步检测
resp, err := client.MsgSecCheck(ctx, "待检测文本", session.OpenID, miniprogram.SecCheckSceneComment)
if err != nil {
    return err
}
if resp.Result.Suggest == "risky" {
    // 拦截内容；"review" 建议转人工复审
}

// 完整参数方法：透传扩展检测字段
resp, err = client.MsgSecCheckFull(ctx, &miniprogram.MsgSecCheckRequest{
    Content:   "待检测文本",
    Version:   2,
    OpenID:    session.OpenID,
    Scene:     miniprogram.SecCheckSceneProfile,
    Nickname:  "用户昵称",
    Signature: "个性签名", // 仅 scene=1 有效
})

// 音视频异步检测：media_type 仅支持 1音频 / 2图片（官方不存在视频类型，提交视频返回 40004）
_, err = client.MediaCheckAsync(ctx, "https://example.com/media.mp3", miniprogram.SecCheckMediaTypeAudio, session.OpenID, miniprogram.SecCheckSceneComment)
// 实际检测结果通过小程序消息推送（wxa_media_check 事件）异步送达，需在消息推送服务中处理
```

### 小程序码

> `GetWxaCode` / `CreateWxaQrcode` 的 `path` 为官方必填参数（`GetWxaCode` 最长 1024 字符、`CreateWxaQrcode` 最长 128 字符，可携带页面参数；空值返回 40159），
> 本库在请求前校验非空。两者生成的码总数与 `getwxacodeunlimit` 无关，上限共 10 万（超限报 45029），已生成数量参考响应头 `Num-Used`。
> 响应为「成功二进制图片 / 失败 JSON」混合格式，本库已统一处理。

```go
// 不限量小程序码（推荐，scene 最长 32 个可见字符，页面通过 onLoad(query.scene) 获取；
// page 不能携带参数，参数统一放入 scene）
qr, err := client.GetWxaCodeUnlimit(ctx, &miniprogram.GetWxaCodeUnlimitRequest{
    Scene:      "id=123",
    Page:       "pages/detail/index",
    EnvVersion: miniprogram.EnvVersionRelease, // release/trial/develop
    Width:      430,
})
if err != nil {
    return err
}
err = os.WriteFile("qrcode.jpg", qr.Data, 0644) // qr.ContentType 为图片类型
// qr.NumUsed 为响应头 Num-Used（官方在 getwxacode/createQRCode 文档记载为「已生成码数量」，
// 用于对照 10 万总量判断余量；getwxacodeunlimit 无总量限制，官方未记载其返回该头，为空属正常）

// 带 path 的小程序码（总数上限 10 万，path 可携带页面参数，最长 1024 字符）
qr, err = client.GetWxaCode(ctx, &miniprogram.GetWxaCodeRequest{
    Path:  "pages/index/index",
    Width: 430,
})
```

### 稳定版 access_token

```go
// 直接调用 /cgi-bin/stable_token，结果不写入缓存，也不改变 GetAccessToken 的默认取 token 路径
token, err := client.GetStableAccessToken(ctx, false) // forceRefresh=true 受官方限频约束
if err != nil {
    return err
}
// token.AccessToken / token.ExpiresIn（正常 7200）
```

### 用户数据解密

```go
var userInfo miniprogram.UserInfo
err = client.DecryptUserInfo(session.SessionKey, encryptedData, iv, &userInfo)
// 内部先校验数据水印 appid 与配置是否一致，不一致直接报错
```

## 四、注意事项

1. **access_token 缓存**：多实例部署请共用数据库存储（`NewClientWithStorageE` + `storage.DBStorage`），避免各实例各自刷新导致互相顶掉。
2. **path 与 scene 限制**：`GetWxaCode`/`CreateWxaQrcode` 的 path 为官方必填（最长 1024/128 字符），两者生成码总数上限共 10 万（超限报 45029），已生成数量参考响应头 `Num-Used`；大量生成请用 `GetWxaCodeUnlimit`（scene 最长 32 个可见字符，page 不能携带参数，参数统一放 scene）。
3. **内容安全 v2 必填参数**：openid（近两小时访问过）与 scene（1-4）；媒体检测仅支持音频/图片，视频需另行处理。
4. **手机号 code 一次性**：`GetPhoneNumber` 的 code 由前端组件获取，单次有效，不可重放。
5. **小程序码混合响应**：成功返回图片二进制、失败返回 JSON，本库 `postWXACodeBinary` 已统一处理，业务侧只需判断 error 后取 `resp.Data`。
